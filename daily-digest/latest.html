Claude Ship lands: Anthropic's agents now review, fix — and approve — your pull requests; the /ship command is rolling out in Claude Code 2.1.33x this weekend, with Anthropic citing 30,000 daily merged changes internally and ~90% of Claude Code's code written by Claude, while analysts call the approval agent "evolution, not breakthrough" and stress-testing begins on what happens when AI signs off on AI

TOP STORYAI AgentsDeveloper Tools

Anthropic's launch post (Nov 23) introduced Claude Ship, in beta: Code Review (generally available) plus two new agents — PR Steward, which fixes failing CI checks, merge conflicts and review feedback but deliberately cannot approve or merge, and Claude Approvals, which reads a policy file in the repo and can approve routine changes on its own, like "a smarter CODEOWNERS file" (docs). TechCrunch (Nov 23) notes the novelty is the delegated approval decision itself — review bots exist, but policy-driven human-replacement sign-off is new; Anthropic recommends starting in observe-only mode, one repo, with monthly spend caps, and The Verge reported the beta launch alongside the weekend's /ship rollout. On the Claude Code team, merged PRs more than doubled from June to September while reverts fell by more than 40%, and the internal monorepo went from ~2,500 to 30,000+ changes merged per day between May and September (heise, Nov 24). InfoWorld (Nov 24) balanced it with analyst skepticism — Gartner's Nitish Tyagi called it "not a breakthrough innovation as much as an evolution," and IDC noted GitHub and GitLab's tighter platform integration — while SiliconANGLE framed it as automating the last human stage of the pipeline. Practical wrinkles this weekend: van de Blaak's Nov 27 field guide finds /ship needs Claude Code 2.1.330+ and GitHub CLI 2.63+, does not fully work on native Windows, and that cloud model aliases now default to Sonnet 5.5 / Opus 5.5 on some providers; Enterprise orgs can claim at least $10,000 in Claude Ship credits by Jan 15, 2027, and all three agents bill on token usage outside plan limits (Anthropic post; heise).

Google makes MCP the only door into Workspace: agents must route through the new MCP servers or CLI from February 1, 2027 — direct REST access is cut off — with free Standard quotas, paid Scaled tiers from April 1, and mandatory human confirmation for consequential actions like sending external email

Platform PolicyAI AgentsPricing

Google's Workspace announcement (Nov 24) made the Workspace MCP servers and Workspace CLI generally available and, unusually, mandatory: "AI agents or similar access tools must use Workspace MCP servers or the Workspace CLI to access Workspace data, rather than calling the Workspace REST APIs directly," with technical enforcement beginning February 1, 2027. The Outpost's roundup (Nov 25) of the Next Web and Dataconomy coverage explains the design logic — existing APIs assumed "a valid login implied a person"; agents run at machine speed, so every agent call now checks company permissions and data-loss rules, and sending email, changing Drive sharing, or bulk edits require a human sign-off. Samonai's Nov 28 brief adds the economics: two usage tiers — Standard free with published rate limits, and Scaled charging above daily free allowances from April 1, 2027 — with Google claiming 99%+ of active developers fit in Standard, and a warning that inactive projects may simply be throttled. SXF Brief (Nov 27) pegs Standard at 5,000 daily requests per project and supported MCP product (some operations count several times), and BizTech Weekly (Nov 24) notes the contractual layer — a new AI Tools Addendum, dedicated OAuth client IDs with least-privilege scopes, and Admin-console audit and revocation. Hello Growth (updated Nov 27) frames the practical to-do: if your agents call Gmail or Drive APIs directly, put the MCP migration on the January plan. Coverage also landed via MindStudio and ExplainX (Nov 27) this week.

ChipDispatch (Nov 28, on The Decoder's Nov 28 coverage of the Nov 24 report) details Humanity's First Exam (HFE) — 544 elementary text-and-image prompts in 136 four-question families, a deliberate inversion of Humanity's Last Exam: the finding is that "high single-shot accuracy masks substantial reliability deficits when models must succeed consistently across repeated rollouts."
