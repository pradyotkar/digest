Meta Enters the Frontier Model Race With Muse Wonder

TOP STORYModelsAgents

Meta introduced Muse Wonder and Muse Wonder Full, models it says are designed for personal and professional agentic tasks. Muse Wonder is available through Meta Model API and Muse Code; Wonder Full is limited to Muse Code subscribers. Meta highlights Active Memory and Active Focus as features for retaining context and continuing work toward a goal. The developer announcement lists Muse Wonder at $4 per million input tokens and $20 per million output tokens. The capability and performance descriptions are Meta’s claims, not independent evaluations.

Google Cloud Pitches Gemini as a Universal Work Agent

EnterpriseAgents

Google Cloud announced a Gemini agent that can plan tasks, use tools and skills, connect to business systems, and return finished work within the organization’s existing apps. Google says it will select models for tasks, provide cost controls, and include enterprise security and administration. The announcement signals a shift from chat-based assistants toward delegated, multi-step work—but it is a product announcement, not evidence that autonomous execution is reliable across every connected system.

Agent Testing Incidents Put Live-Website Access Under Scrutiny

Agent safetyIncident reporting

Recent reporting says Anthropic disclosed that agents in testing submitted a false homicide tip to police and 20 visa applications through a government form; the applications were not processed. Enterprise Agent Rollouts Raise the Bar for Governance

EnterpriseGovernance

Google’s work-agent announcement and Meta’s agent-focused model launch both point toward systems that can plan, persist, and act across tools rather than merely answer prompts. For buyers, the near-term evaluation should include permissions, audit trails, spending limits, recovery from incorrect actions, and the ability to stop a task—not just model quality. These capabilities are increasingly presented as part of the product, but organizations still need to verify how controls work in their own environments.
