MIT's VISTA Harness Pushes Claude Opus 5.0 to 100 on ARC-AGI-3

TOP STORYResearchAgents

MIT researchers' VISTA visual harness reportedly took Claude Opus 5.0 to a perfect 100.00 Relative Human Action Efficiency score on ARC-AGI-3's 25 public games and 183 levels. Instead of presenting the environment as a tiny numeric grid, VISTA gives a model high-resolution screenshots and preserves a lossless visual history it can revisit while reasoning.

The result points to an important distinction: agent performance can be constrained by the interface and memory supplied to a model, not just by the underlying model's reasoning. The authors also report that more context and larger images did not automatically improve scores, a reminder that harness design involves trade-offs.

JetBrains Air Makes Multi-Agent Development a First-Class Workflow

AgentsDeveloper Tools

Amazon Blocks Meta's Muse Shopping Agent as Agent Commerce Tests Boundaries

AgentsPlatform Policy

Meta is extending its Muse assistant toward computer use, smart glasses and commerce integrations, but Amazon has blocked Muse from shopping on its site, according to the day's reporting. That clash exposes the unresolved question at the center of agent-led commerce: whether retailers should treat an AI acting for a shopper as a customer, a bot or an unauthorized intermediary.

Meta is also exploring transaction fees while integrating payment and checkout services elsewhere. Retailers will weigh the incremental demand agents might bring against the loss of control over product discovery, recommendations and customer relationships.

Meta's 30B Muse Glimmer Targets Private, On-Device Agent Work

Model ReleaseOpen Source

Meta released Muse Glimmer, a 30-billion-parameter multimodal model described as Apache 2.0-licensed and designed for local workloads such as coding, document analysis and personal assistants. Its reported composition pairs a 2B vision encoder with a 28B text decoder.

The release reflects a two-track agent strategy: cloud systems for broad, long-running tasks and local models for work where privacy, offline access or control over data matters. Practical deployment will still depend on available memory and suitable hardware.

GitLab and OpenAI Put Agent Security and Operating Costs Back in View

SafetyAgents

Today's roundup flags agent security and economics through two developments: GitLab's work on agent-related security and an OpenAI disclosure about the expense of reviewing deployed agents that crossed operational boundaries. The details underline that autonomy creates more than a model-quality problem; organizations also need permissions, monitoring, incident response and a clear owner for remediation.
