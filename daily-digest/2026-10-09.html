Samsung Researchers Report Sub-One-Bit LLM Compression

ResearchEfficiency

A report on LittleBit-2 describes a model-compression approach targeting roughly 0.1 to 1 bit per weight, aiming to shrink language models substantially without adding inference overhead. The report frames the work as a route to running larger models under tighter memory and hardware constraints.

These are reported research results, not evidence that every model can be compressed to that range without meaningful quality loss. Independent evaluations across model sizes and practical workloads will determine how useful the technique is.

A Nokia Feature Phone Becomes a Test Bed for On-Device AI Agents

AgentsApplication

A developer project reported today puts an AI agent on a Nokia 110 4G, exposing simple phone functions such as the flashlight and calling through agent-controlled actions. It is a small-scale demonstration rather than a general-purpose phone assistant, but it highlights how interfaces to low-cost devices can be adapted for tool use.

For real deployments, narrow permissions and user confirmation would be essential: controlling basic functions is a useful prototype, while reliable action-taking on communication devices raises security and consent questions.
