TanStack AI reaches 1.0, putting a stable foundation under agent apps

TOP STORYDeveloper ToolsAgents

TanStack has released version 1.0 of its provider-agnostic AI toolkit. The project says the stable core now covers chat, tools, persistence, sandboxes and agents, with 23 provider adapters and support for eight UI frameworks. The release also adds subagents, portable agent skills, computer use and MCP server support.

A separate agent harness supports long-running sessions, background work and typed agent orchestration, but its APIs remain explicitly experimental. That separation matters: teams can adopt the stable interfaces without treating the newest orchestration layer as production-settled.

Google Cloud brings OpenAI models into its enterprise marketplace

CloudEnterpriseModel Access

Google Cloud is putting OpenAI models into private preview for selected business customers, including GPT-6 Astra, GPT-6.1 Sol and GPT-6 Luna. Customers will be able to access them through Google Cloud Marketplace and APIs, with usage consolidated on a Google Cloud invoice and applied to eligible cloud commitments.

Google says prompts, context and outputs will stay within designated data boundaries and will not train foundation models. For buyers, the practical shift is distribution and procurement: compare providers and route workloads while managing spend and controls through an existing cloud relationship.

Nvidia expands its local AI stack from personal agents to multi-system clusters

HardwareLocal AI

Nvidia used GTC Berlin to frame a broader local-AI lineup: RTX Spark for personal agents, DGX Spark for developers and DGX Station for enterprise workloads. The event coverage reports RTX Spark shipments beginning worldwide, a new local desktop agent called Underdog, and 64GB DGX Spark systems starting to roll out on October 23.

DGX Spark can now be configured in clusters of up to eight systems, according to the report, while software updates target local model setup and faster agentic inference. This pushes more experimentation and deployment toward privately run hardware, though the real trade-off remains capability and operating cost versus cloud flexibility.

Meta says Muse has passed 10 million users as it explores commerce fees

Consumer AgentsBusiness Model

Meta CEO Mark Zuckerberg said more than 10 million people in the U.S. and Canada have set up Muse agents since the September 8 launch, according to the company’s October 21 earnings call. Meta says consumer use will be free within limits, with charges possible for additional tokens or more advanced models.

The company is also considering a fee for businesses when Muse helps complete a sale. That points to a commerce-based monetization path for personal agents: adoption could be subsidized for consumers while merchants pay for attributed transactions. The user figure and plans are company-reported, not independently audited.

Source: Fortune — “Mark Zuckerberg says over 10 million people used Meta’s Muse—and demand was so high, he had to get Stripe to raise credit limits” (published October 22, 2026). Retrieved October 23, 2026.

OpenAI opens a low-cost Decisions API for structured, high-volume calls

APIPricingDeveloper Tools

OpenAI’s Decisions API became broadly available to users with API access on October 22, according to Gate News. Rather than returning prose, the endpoint is designed for structured outputs such as probabilities, choices and scores, for tasks like routing, classification and repeated micro-decisions.

The report lists a price of $0.10 per million input tokens with no output-token charge, and says it runs on GPT-6 Luna. If the price and performance hold for real workloads, this could make frequent lightweight decisions cheaper to delegate to a model—while still requiring teams to test accuracy and failure handling.

Source: Gate News — “OpenAI Opens Decisions API to All Users at $0.10 Per Million Tokens” (published October 22, 2026). Retrieved October 23, 2026.
